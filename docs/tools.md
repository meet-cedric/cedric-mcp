# Cedric MCP tools

The 134 tools the Cedric server exposes at `https://app.meet-cedric.com/api/v1/mcp`, grouped by what they do. Every call acts as the signed-in person, inside their workspace.

Parameters marked `?` are optional. Call `getting_started` first: it returns the full usage guide over the wire, and `tools/list` returns each tool's complete input schema.

Risky tools (sending messages or mail, running code, creating automations) return `pending_approval` under a standard key or browser sign-in, until a person approves. See [approvals](api.md#approvals).

Generated by `scripts/build-tools-doc.py` from the live `tools/list`.
